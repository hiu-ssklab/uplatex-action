# これは何か

卒研企画発表,
卒研小論文を作成する際の upLaTeX のテンプレートと,
Github Action のレシピ.

このリポジトリをフォークして,
自分で適宜書き換えて利用されたい.

なお, 提出ファイル名は ```s 学籍番号ローマ字氏名.pdf``` と指定されている
(例えば ```s2111999yamada.pdf``` など).

push 前に [.github/workflows/latex.yml](.github/workflows/latex.yml)
の FILE_NAME を更新しておくこと.

## 小論文とは?

ここでは, 7 月の卒研企画発表会および 1 月の卒研発表会 (後) に提出する A4 2 ページ程度の短かい論文のこと.

卒研小論文の様式は
[卒業研究の手引き](https://polite.do-johodai.ac.jp/moodle/course/view.php?id=23)
を参照のこと.

###  論文構成

以下のとおり, 3 〜 5 節程度で構成しよう.

- はじめに
  - 背景・課題・目的はこの節にまとめる
  - 「背景」とは, その研究テーマの位置づけを説明するものであり,
    **あなたがその研究に取り組む理由等の個人的な背景ではありません**
  - 関連研究もこの中で適切に紹介すること (独立した節にしない)
- 本研究の目的
- 「実験」「結果」など「やったこと」に対応する章立て
  - だらだら書かないこと.
  ー 長くなる場合は「実験」「結果」など 2 〜 3 節に分けても OK
- まとめ
  - 7 月提出の企画発表会小論のみは「スケジュール」を含めてください.
    ガントチャートがあれば良いです. 

### 注意点

- 最長で 2 ページしか無いので, 細かく分けすぎないこと
- subsection は使ってもよいけど必要最小限に留める.
  - subsubsection は使わない
- 節の構成には文量のバランスを意識すること.
  長すぎる節や短すぎる節をつくらない
- 参考文献は 1 〜 3 件程度引用すること
- 画像を必ず貼りつけること
  - 卒研企画発表会: ガントチャート
  - 卒研小論: 概要や結果など.
- 卒研小論は「進捗」ではなく「成果報告」です. 
  基本的に, 研究が完了した体で書きます. 
  - 一般的な Future Works (残された課題) という形で今後について書くのは OK
